# Agent Skill: README Generator (V1 - Basic Checklist)
**Version:** `1.0.0`
**Type:** Minimal Guidelines

## Instructions
When writing a README for a software project, ensure you include the following sections:
1. Project Title
2. Description of what it does
3. Key Features list
4. Tech Stack
5. Installation instructions
6. How to run the project
7. License

Make sure formatting uses standard Markdown headers.
