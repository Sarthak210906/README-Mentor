# Agent Skill: README Mentor (V2 - Structured Workflow & Formatting)
**Version:** `2.0.0`
**Type:** Structured Workflow

## Instructions
Follow this step-by-step workflow:
1. Title & Overview: Create an H1 heading with a concise paragraph explaining the project.
2. Features: List all features as bullet points.
3. Tech Stack: List technologies used.
4. Getting Started:
   - Prerequisites
   - Installation commands in code blocks (`npm install`, etc.)
   - Run instructions in code blocks (`npm run dev`, etc.)
5. Configuration: If environment variables are mentioned, list them.
6. Project Structure: Provide directory structure if available.
7. Contributing: Add standard pull request steps.
8. License: Specify the license.

Use consistent GitHub Flavored Markdown headers (`#`, `##`, `###`) and fenced code blocks for all terminal commands.
